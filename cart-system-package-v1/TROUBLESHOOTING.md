# TROUBLESHOOTING.md — Cart System Package v1

---

## Failure Mode Reference

| Symptom | Likely Cause | Files To Check | Safe Next Action | Do Not Do |
| ------- | ------------ | -------------- | ---------------- | --------- |
| `ReferenceError: crypto is not defined` in orders-create logs | Node runtime does not expose `crypto` as global, or Node version is below 15 | `functions/orders-create.mjs` line 94 | Add `import { randomUUID } from "node:crypto"` and use `randomUUID()` instead of `crypto.randomUUID()` | Do not change Square or Supabase config |
| Supabase returns 401 | Wrong or missing Supabase key in env vars; service role key used where anon key expected or vice versa | Netlify env vars: `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | Verify correct key type is used in each function; check Netlify env var values are set and not placeholder | Do not hardcode keys in code |
| products-get returns empty array | No products in Supabase with `active=true`; Supabase env vars missing; RLS blocking access | `functions/products-get.mjs`, Supabase products table | Check Supabase table for active products; verify `SUPABASE_ANON_KEY` is correct anon key (not service role) | Do not disable RLS |
| Square card does not load (placeholder text shows) | `square-config` failed; Square env vars missing or wrong; SDK URL wrong for environment | `functions/square-config.mjs`, Netlify env vars: `SQUARE_APP_ID`, `SQUARE_LOCATION_ID`, `SQUARE_ENVIRONMENT` | Call square-config endpoint directly to inspect response; verify App ID prefix matches environment | Do not hardcode Square credentials in checkout.html |
| Wrong environment returned by square-config | `SQUARE_ENVIRONMENT` env var not set or misspelled; App ID prefix doesn't match environment | `functions/square-config.mjs`, Netlify env vars | Confirm `SQUARE_ENVIRONMENT=sandbox` and `SQUARE_APP_ID` starts with `sandbox-`; check Netlify env var casing | Do not change to production without written approval |
| orders-create fails | Missing or placeholder Supabase env vars; crypto issue; wrong request body shape | `functions/orders-create.mjs`, Netlify function logs | Check function logs for specific error; verify env vars in Netlify dashboard | Do not change payment logic to fix an env var issue |
| Square payment fails | Wrong access token; wrong location ID; sandbox token used in production (or reverse); invalid card used in test | `functions/orders-create.mjs`, Netlify env vars: `SQUARE_ACCESS_TOKEN`, `SQUARE_LOCATION_ID` | Check Square error detail in Netlify logs; verify all Square env vars match the correct environment (sandbox vs production) | Do not retry with a real card in sandbox |
| Supabase order insert fails | Wrong service role key; Supabase project paused; table doesn't exist; column mismatch | `functions/orders-create.mjs`, Supabase dashboard | Check Netlify logs for the full Supabase error text; verify `orders` table exists with correct schema | Do not delete and recreate the table if real orders exist |
| Order email missing | Netlify Forms `order-notification` not set up; site URL not accessible from function; form POST returns non-200 | `functions/orders-create.mjs` `sendOrderNotification()`, Netlify Forms dashboard | Add hidden `order-notification` form to a deployed HTML page; check Netlify Forms dashboard for submissions | Order still succeeded — do not reprocess payment |
| Cart item does not add | `window.PIXY_PRODUCTS` not loaded when add is called; product key not found | `assets/js/pixy-cart.js`, `assets/js/products.js` | Check browser console for `[pixy-cart]` warnings; confirm `products.js` is loaded before any add-to-cart calls | Do not modify pixy-cart.js without a full cart test |
| Cart update/remove fails | `window.PIXY_CART` is null; pixy-cart.js not loaded; localStorage write failed | `assets/js/pixy-cart.js`, page script load order | Check browser console; confirm pixy-cart.js is included in the page | |
| Checkout button does nothing | `window.PIXY_CART.open` is null (cart.js not loaded); click handler not wired | `assets/js/cart.js`, `assets/js/pixy-cart.js` | Check browser console; confirm both scripts are loaded in order (pixy-cart.js first) | |
| Netlify function not found (404) | Functions directory mismatch — `netlify.toml` says `netlify/functions` but files are in `functions/` | `netlify.toml` line 5, Netlify site settings | Correct `netlify.toml` to `directory = "functions"` or set override in Netlify site settings | Do not delete function files |
| Secrets appear in logs | Env var value accidentally logged; debug code left in | All function files; `functions/orders-create.mjs` | Rotate the exposed key immediately; review function code for any `console.log(process.env.XXX)` | Do not commit new key values to git |
| functions directory not resolving | `netlify.toml` has `directory = "netlify/functions"` but no `netlify/` subdirectory exists | `netlify.toml` line 5 | Correct to `directory = "functions"` | Do not create a `netlify/functions/` directory and move files without testing |
